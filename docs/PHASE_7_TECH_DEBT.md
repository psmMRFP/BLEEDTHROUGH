## 7.6-R 研究反馈

- 四类基础观察仍使用既有 ID；Severance = Rift + Cauterization + White Sanctuary，Symbiosis = Rift + Bioindustry。结果是独立知识，可同时持有，不锁玩法路线或删除 Bleed Zone。
- 新增可见 Advancement 页面与中英文本；新观察只提示一次，首次满足条件时只提示一次。周期同步补发旧存档／重载后缺失的 Advancement，不重发已有提示。
- Rift 观察只在未取消且方块／物品交互均非 DENY 时记录；极寒已记录后跳过重复条件检查。烧灼和 Heart Pump 沿用既有成功分支记录。
- 单测覆盖乱序、重复、旧／未知观察值与状态复制；GameTest 只证明专服能加载所有研究进度 JSON。GameTest 模拟玩家没有真实网络通道，无法代表真实玩家的提示、奖励、死亡 Clone、NBT 重连或多人隔离，这些保留 `[~]`。

## 7.7-A 遥测说明

默认关闭。开启后按配置 tick 数写 `world/data/meatscape-soak.csv`，原文件超 8 MiB 后创建新文件；旧日志不自动删除。发现旧版表头时先保留为 `meatscape-soak-legacy-*.csv`，再创建新格式，绝不把 11 列与 29 列混写。每次启用生成新 session ID，重启追加 CSV 时仍可按 session 区分。构建提交来自开发运行配置的 Git HEAD；非该运行配置显式记为 `unknown`。

窗口计时是 Forge ServerTick START 到 END 的事件跨度，不能解释成完整服务器 tick 的精确 MSPT。正向／回退总量与峰值、超全局和每 Rift 预算次数按每 tick 累计；每窗最多 64 个 Rift 单独计数，其余归入 `overflow_rift_work`，下窗清空。未计算 p95/p99。首个窗口 GC 差值、首次后台存档扫描结果为空；扫描或文件大小读取失败同样为空，不写假零。`world_bytes` 排除 `meatscape-soak*.csv`；`telemetry_bytes` 是当前 CSV 文件大小。

写失败会警告并保留服务器运行；每段连续失败只记录首次警告。后台线程只持有存档路径，不持有世界对象，服务端关闭或运行中禁用时关闭线程。数据文件和构建缓存保持在工作区或 Gradle 全局目录，绝不使用系统临时目录。

## 7.7-B 独立无人专服

`scripts/phase7-soak.sh 2` 是两分钟在线演练；`scripts/phase7-soak.sh 180` 是三小时累计运行，`0` 仅检查启动／重启。脚本要求现有 `run/eula.txt` 已被用户接受，在 `run/phase7-soak` 创建固定 seed `76507650` 的专用世界，仅监听本机端口 25570；不覆盖既有专用世界、配置或历史日志。夹具包含常加载区、活跃与休眠 Rift、已喂养受伤膜墙、Heart Pump、保护用箱子及远端区块的加载／卸载。Heart Pump 仅放置不代表自动加工；没有真实玩家的自然发现、生态观察、交互或网络同步不能算通过。

脚本记录命令、UTC 时间、退出码、构建提交、Java 版本、两段服务器日志和 CSV，执行 pause/resume、reload、干运行及有限真实 rollback、save-all、正常 stop 与重启。短演练只能验证控制链；三小时正式运行还需冻结负载与对照阈值，审查两段 session ID、预算违规、队列、GC 低水位、存档增长与异常日志。运行数据保存在被 Git 忽略的工作区目录，需人工归档。
