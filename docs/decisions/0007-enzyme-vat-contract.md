# ADR 0007：Enzyme Vat 回收契约

状态：已接受（2026-09-16）

- `meatscape:enzyme_vat` 是第一台独立 Core 的酶化处理组件。Raw Tissue 以一份一份的有界输入处理；一份 Collagen 作为催化剂保留，完成后产出一份 Nutrient Paste。
- Vat 保存组织、催化剂、产物和进度四个夹紧的标量。停止、区块卸载和存档重启均从同一进度恢复；满产物槽停止处理，不消耗组织或催化剂。
- 无手持物交互时领取全部产物；背包放不下时掉落，避免物品静默消失。方块配方为普通数据包配方，随服务器数据包 reload 重新加载。
- 该阶段不接入 Create、IE、桶装流体、自动物流或复杂容器接口；后续酶化扩展须保持输入／输出守恒与重载安全。

## 验证

- 自动验证催化剂不消耗、进度序列化、完成产物和普通配方数据加载。
- 实际玩家配方 reload、停机恢复、背包满领取、平衡与正式资产保留 `[~]`。
