# ADR 0009：Neural 局部信号契约

状态：已接受（2026-09-23）

- `neural_sensor` 检测六面相邻 Heart Pump／Artery 的 Hematic 储量；任一节点达到 100 mB 时输出 15 级神经信号。它不读取红石，避免执行器通过外部红石线重新激发传感器。
- `neural_fiber` 接收相邻传感器或纤维的最高信号，每经过一格衰减一级；`neural_actuator` 接收相邻纤维的信号并输出同级原版红石。执行器不能作为纤维输入；无源环路至多在 15 级内衰减归零。
- 三个部件空手右键切换启用状态。信号与开关使用原版 BlockState 存档；本阶段没有自定义持久数据，因此没有新增数据格式版本。进入已加载区块后的首次 tick 和每 20 tick 的分散轮询会重新计算节点状态。
- 每个服务器维度每 tick 最多处理 64 个待更新坐标；去重队列只存不可变坐标，不持有区块、实体或节点引用。位置已卸载时跳过；维度卸载时清空队列。相邻查询仅在区块已加载时进行，不主动加载区块。
- 三种配方、BlockItem、掉落与暂用原版材质均属于 Core；不要求 Create／IE。正式材质、玩家搭线可读性、长线负载和实际区块卸载／重载体验待验证。

## 验证

- Java 17 `test` 通过；专服 GameTest 36 项通过，新增场景覆盖预算、供液传感、逐格衰减、红石执行、关闭／恢复、断源、无源环路消退和服务器自然 tick 传输。
- 真实玩家与双客户端观测、代表性大规模网络性能、专服长时间卸载／重载留 `[~]`。
